## 2. Core Features & Architecture

### A. Data Schema (`movies.json` + `data.js`)
Each movie item will strictly include:
- `id`: Unique slug identifier (e.g., `"interstellar"`, `"blade-runner-2049"`)
- `title`: Movie title
- `tagline`: Editorial punchline
- `year`: Release year
- `rating`: Critic/User score (e.g., `8.7`)
- `duration`: Runtime (e.g., `"2h 49m"`)
- `genres`: Array of tags (`["Sci-Fi", "Adventure", "Drama"]`)
- `director`: Director name
- `cast`: Array of lead actors
- `synopsis`: Complete plot summary
- `posterUrl`: High-resolution portrait poster image URL
- `backdropUrl`: Cinematic wide banner landscape image URL
- `viewUrl`: Direct streaming / official trailer watch link
- `featured`: Boolean flag for hero recommendation banner

**Data Persistence & JSON Saving:**
- Loads initial catalog from `data/movies.json` or fallback embedded seed data.
- User additions/edits persist to `localStorage`.
- Includes an "Export JSON" button so users can download their updated JSON data file directly.
- Includes an "Add Movie" modal with validation for `posterUrl` and `viewUrl`.

### B. Page 1: Movie Recommendation Hub (`index.html`)
- **Spotlight Hero Banner**:
  - Highlights a top recommendation with atmospheric backdrop glow.
  - One-click "Watch / View" external link and "More Info" detail page transition.
  - Interactive hero switcher / preview thumbnails.
- **Instant Search & Filter Bar**:
  - Live fuzzy search by title, director, or actor.
  - Keyboard shortcut (`/` to focus search instantly).
  - Category pills (All, Sci-Fi, Action, Drama, Animation, Thriller, Romance).
  - Sort selector (Highest Rated, Newest, Title A-Z).
- **Recommendation Grid**:
  - Staggered entrance animation for cards (`calc(var(--i) * 45ms)`).
  - Poster cards with rating badge, release year, genres, and quick watchlist toggle.
  - Fluid hover elevation with hardware-accelerated transforms.
  - Direct navigation to `detail.html?id=<movie-id>`.
- **Add Movie Modal**:
  - Clean floating dialog to add new movies with live poster preview.
  - Saves new entries to JSON state in `localStorage` and updates the grid immediately.

### C. Page 2: Cinematic Detail Page (`detail.html`)
- **Deep Immersion Backdrop & Layout**:
  - Full-width hero backdrop with multi-stop linear gradient vignettes (`mask-image` / dark scrim).
  - Breadcrumb navigation back to `index.html` with keyboard shortcut support (`Escape` or `Back`).
- **Media & Action Center**:
  - High-res floating poster with specular highlight border.
  - Primary "Watch Now / Link to View" call-to-action button (opens external view/trailer link in new tab or video modal).
  - Secondary "Add to Watchlist" interactive button with micro-interaction state change.
- **Comprehensive Metadata Grid**:
  - Synopsis, release year, runtime, age rating, director, and interactive cast chips.
  - Rating metrics (IMDb / Rotten Tomatoes styled breakdown).
- **"More Like This" Curated Recommendations**:
  - Related movies matched by overlapping genres or director.
  - Direct links to reload `detail.html?id=...` smoothly.

## 3. Design Engineering Polish (`emil-design-eng`)

1. **Micro-interactions & Physics**:
   - Buttons: `transform: scale(0.97)` on `:active` with `160ms ease-out` transition.
   - Smooth entrance from `scale(0.95)` and `opacity: 0` (never from `scale(0)`).
   - Custom easing curves:
     ```css
     --ease-out: cubic-bezier(0.23, 1, 0.32, 1);
     --ease-in-out: cubic-bezier(0.77, 0, 0.175, 1);
     ```
   - Hover animations strictly gated behind `@media (hover: hover) and (pointer: fine)`.
   - UI transitions kept under 250ms for snappy responsiveness.
2. **Visual Hierarchy & Typography**:
   - Modern system font stack with fallback to Inter/Plus Jakarta Sans.
   - Deep cinematic noir palette: `#08090C` background, `#12151E` surface cards, subtle luminous borders `rgba(255,255,255,0.08)`.
   - Polished SVG icons (Play, Star, Bookmark, Search, Filter, Plus, ArrowLeft, ExternalLink).

## 4. Implementation Steps

1. **Seed Data (`data/movies.json`)**:
   - Populate with 10+ real, iconic movies with tested, high-res Unsplash/TMDB poster and backdrop URLs and YouTube trailer/view URLs.
2. **Data Layer (`js/data.js`)**:
   - Implement storage manager: fetch initial JSON, sync with `localStorage`, support `addMovie(movie)`, `getMovieById(id)`, `getAllMovies()`, and `exportJSON()`.
3. **Core Stylesheet (`css/style.css`)**:
   - Configure CSS design tokens, custom curves, modal transitions, grid layout, responsive queries, and utility classes.
4. **List Page (`index.html` & `js/app.js`)**:
   - Build hero spotlight, search/filter controls, movie grid renderer, and the "Add Movie" modal.
5. **Detail Page (`detail.html` & `js/detail.js`)**:
   - Build detail view parser, dynamic template filler, "link to view" triggers, and related recommendation carousel.
6. **Verification & Testing**:
   - Launch local web server and verify both pages, query parameter navigation, responsive design on mobile and desktop, search filtering, and JSON add/export workflow.
